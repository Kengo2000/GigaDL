# GigaDL — ギガファイル便ダウンローダー / アップローダー（Mac / Windows）

詳しい手順は「GigaDL_かんたん説明書.pdf」を見てください。

## インストール

### Mac
1. zipを解凍する
2. ターミナルに `bash ` と打ち（後ろに半角スペース）、`install.command` をドラッグしてEnter
3. `/Applications/GigaDL.app` ができて起動します。以降は Spotlight で「GigaDL」

### Windows（10 バージョン1809以降 / 11）
1. zipを解凍する（右クリック →「すべて展開」）
2. `install.bat` をダブルクリック
   - 「WindowsによってPCが保護されました」と出たら「詳細情報」→「実行」
3. Pythonが無ければ自動で入れてから、スタートメニューとデスクトップに「GigaDL」を作って起動します

どちらも、インストール後は解凍したフォルダを削除してかまいません。
アップデートは新しいzipで同じ手順をもう一度実行するだけです。

## 使い方
- URLを貼って「追加してダウンロード」（Mac: ⌘↩ / Windows: Ctrl+Enter）。複数行まとめて貼ってもOK
- クリップボードにギガファイル便のURLがあれば、ウィンドウを前に出したとき自動で入力欄に入ります
- まとめページ（複数ファイル）は1ファイルずつ一覧に展開されます
- パスワード付きは右上の欄に入れてから追加。後からでも行を選んで「パスワード入力…」

## 保存先
- 「保存先」のプルダウンで切替。最近使ったフォルダ10件を覚えています
- 「追加するたびにフォルダを選ぶ」にチェックすると、URLを追加するごとにフォルダを聞きます
- 一覧の「保存先」列でファイルごとの保存先が見られます
- 追加後でも、行を選んで「保存先を変更…」。途中まで落とした分も新しいフォルダへ移して続きから再開します

## アップロード（「アップロード」タブ）
- ファイルやフォルダをドラッグ＆ドロップ（フォルダは中のファイルを1つずつ）
- 保持期限（3〜150日）とパスワード（半角英数1〜4文字）を選べます。パスワードは送信後にも設定可
- 公式サイトと同じく100MBずつ順番に送信。相手には元の1ファイルで届きます
- 途中で切れたら切れた分だけ送り直し、アプリを閉じても次回は続きから再開
- 最後にギガファイル便側のサイズを確認してから「完了」
- 「送る文面をコピー」でファイル名・URL・パスワード・期限をまとめてコピー
- 「まとめて1つのURLにする」にチェックすると、全部送り終わったら1つのURLにまとめます（後から「選んだファイルをまとめる…」でも可）
- 「1つのZIPにして送る（無圧縮）」にチェックすると、フォルダ構成のまま1つのZIPに固めてから送ります（作業用ZIPは送信後に自動で削除。作る場所は「ZIPの作業場所…」で変更）

## レジューム
- 途中データは保存先に `ファイル名.gdlpart` として残り、続きから再開します
- 回線が切れたら自動で再接続して続きから（最大30回、間隔は最大30秒）
- アプリを閉じても、次回起動時に自動で続きから再開（チェックで切替）
- ダウンロード中はPCのスリープを防止します

## 置き場所 / アンインストール
| | Mac | Windows |
|---|---|---|
| アプリ | /Applications/GigaDL.app | スタートメニュー・デスクトップのショートカット |
| プログラム | ~/Library/Application Support/GigaDL | %LOCALAPPDATA%\GigaDL |
| 設定・一覧・ログ | ~/Library/Application Support/GigaDL | %APPDATA%\GigaDL |

アンインストールは上の場所を削除するだけです（自動で入れたPythonは残ります）。

## 補足
- 同名ファイルがある場合は「名前 (1).mp4」のように別名で保存します
- Windowsの完了通知はタスクトレイのGigaDLアイコンから出ます
- ページ解析は fireattack/gfile（GPL-3.0）のロジックを参考にしています。
  ギガファイル便側のページ構成が変わると読み込めなくなることがあります
